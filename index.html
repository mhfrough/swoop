Swoop for Chrome

The whole page, top to bottom, in one picture.

Click the Swoop button or press Alt Shift S. Swoop scrolls the page, takes it one screen at a time and joins the parts into one tall image. The editor opens in a new tab.

  • Headers show once. Sticky menus and cookie bars are not repeated down the picture.
  • Nothing is left blank. Swoop scrolls through first, so lazy images and fade-in effects have loaded.
  • Web apps work too. Pages that scroll inside a box are captured by that box.
  • Save as PNG, JPG or WebP, or copy straight to the clipboard.
  • No scary install warning. Swoop can only see a tab after you click its button.

Swoop for Windows and Linux

Press Print Screen. Drag. Done.

Swoop waits in the tray. Press Print Screen and the screen freezes, so menus and tooltips stay put while you select. Mark up the part you chose right where it is, then press Enter to copy it or Ctrl S to save it.

  • Tiny. A download of a few megabytes. It uses the web view your system already has.
  • Starts with your computer, with a switch in the tray menu to turn that off.
  • Linux is not an afterthought. Builds for Debian, Ubuntu, Fedora and an AppImage for the rest.
  • Saves to Pictures/Swoop with the date and time in the name. Ctrl Shift S asks where.

Private by design

Nothing is uploaded. There is nowhere to upload to.

Some screenshot tools put your pictures on a public server and hand out short links. Old links like that could be guessed, so strangers could read other people's screenshots. Swoop has no server at all. Your pictures go to your clipboard or your disk, and nowhere else.

Questions

Is Swoop really free?

Yes. Every tool is free, there are no ads and there is no paid version. Swoop is open source under the MIT licence.

Print Screen opens the Snipping Tool instead of Swoop.

Windows 11 gives the Print Screen key to the Snipping Tool. Open Settings, then Accessibility, then Keyboard, and turn off Use the Print screen key to open screen capture. Swoop's settings window has a button that takes you there. If another screenshot app such as Lightshot or ShareX is running, it may have the key too: quit it, and Swoop takes the key the next time you open its settings.

Print Screen does nothing on Linux.

On Wayland, apps are not allowed to listen for keys. Add a keyboard shortcut in your system settings that runs swoop --capture. On X11, Print Screen works out of the box. You can always click the tray icon.

Windows says the installer is from an unknown publisher.

The installer is not code-signed yet, so SmartScreen may warn the first time. Choose More info, then Run anyway. You can check the source and build it yourself on GitHub.

How long a page can the extension capture?

Chrome limits a picture to 32,767 pixels tall. Longer pages are scaled down to fit, and the editor tells you when that happens.

Why does a long page take a few seconds?

Chrome allows an extension to take two pictures of a tab per second. Swoop also scrolls through the page once first, so images and animations have loaded before it captures.

Does it work on a Mac, or in Firefox or Edge?

Edge can install the Chrome extension as it is. A Mac app and a Firefox version are planned, but not ready yet.

What permissions does the extension ask for?

Only what it needs: the tab you click Swoop on (activeTab), running the capture script there, a right-click menu item, and storage for your settings and your last 12 captures. It cannot read any site you have not clicked Swoop on.
