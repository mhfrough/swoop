Take a screenshot

Press Print Screen, drag over any part of the screen, mark it up, then copy or save.

Windows is using Print Screen for the Snipping Tool. Turn off Use the Print screen key to open screen capture so Swoop gets the key.

Another app is using the Print Screen key. It is often another screenshot app, such as Lightshot, ShareX or Greenshot. Quit it or change its key, then come back to this window and Swoop will take the key. Until then, click the tray icon to capture.

On Wayland, apps cannot listen for keys. Bind swoop --capture to a key in your system's keyboard shortcuts.
